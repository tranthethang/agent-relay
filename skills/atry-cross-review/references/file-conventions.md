# File conventions

A run directory is `.agent-relay/{YMD}-{id}-{slug}/`.

`{YMD}` is the creation date `YYYYMMDD`. `{id}` is 10 or 11 digits. `{slug}`
matches `^[a-z]+(-[a-z]+)*$`. `atry run new` chooses the id and the date.
Do not rename the directory.

This file is generated from `specs/70-storage-and-git/00-directory-conventions/` by
`scripts/maint/sync-references.ts`. Edit those parts. Do not edit this file
or the copies under `skills/*/references/`.

| Purpose      | Path                                  | Writer                         |
| ------------ | ------------------------------------- | ------------------------------ |
| Overview     | `10-plan/overview.md`                 | Agent, after `atry plan new`   |
| Task input   | `10-plan/tasks.input.json`            | Agent, from the scaffold       |
| Task index   | `10-plan/index.json`                  | `atry plan done`               |
| Task prose   | `10-plan/T1.md`                       | `atry plan done` scaffolds it  |
| Implement    | `20-implement/T1.md`                  | Agent, after `atry task start` |
| Self-review  | `30-self-review/01.md` and `01.json`  | Agent, after `atry review new` |
| Cross-review | `40-cross-review/01.md` and `01.json` | Agent, after `atry review new` |
| Distill      | `90-distill/manifest.json`            | `atry distill`                 |
| Cache        | `run.json`                            | `atry`                         |
| Events       | `events.jsonl`                        | `atry`                         |
| Locks        | `locks/T1.lock`                       | `atry claim`, while held       |

Markdown is prose. `atry` does not parse it. JSON that an agent fills starts
as a scaffold with every key present.

Brainstorms live at `.agent-relay/brainstorms/{YMD}-{slug}/` with `notes.md`
and `open.json`. A brainstorm is not a run.

## Names

Task ids are `T1`, `T2`, and so on, up to 8 tasks. Deps point at earlier ids
only. `files` entries are repo-relative paths. A directory overlaps a file
under it during `atry claim`.

Tool names are `cursor`, `claude-code`, `cowork`, `codex`, `antigravity`,
`kiro`, or `unknown`.

## Review files

`atry review new <run> self` writes the next pair under `30-self-review/`.
`atry review new <run> cross --model <model>` writes the next pair under `40-cross-review/`.
Names are `01.md` and `01.json`, then `02`, and so on. A later review does
not rewrite an earlier pair.

The markdown file is prose under `# self` or `# cross`. Each question starts
at column zero as `- Q<n>: `. The JSON file has `schema`, `kind`, `tool`,
`model`, `fixed`, and `open`. Each `open` item is either `q`, `a`, and `b`, or
`q` and `need`. Review JSON does not contain a test result.

`atry review done` validates the latest JSON for that kind and appends a
`completed` event. It runs the base policy's `testCommand`, when configured,
and writes output to the matching `.test.log` file. It refuses when Markdown
question cards and JSON open items differ. Use `atry review decide <run>
Q<n> <answer>` to record a user's answer. Close reads the review whose
`completed` event is newest.

## Parallel claim

Several sessions can work on one run. `atry claim <run> <task> --session <tag>`
writes `locks/<task>.lock` and starts the task. `atry release` removes that
lock when the session matches.

`claim` refuses a task when another session holds a lock whose `files` overlap.
The same session may hold overlapping tasks. `claim` does not stop edits
outside the recorded paths and does not create a worktree.

A task with deps stays unclaimable until each dep is `done` or `skipped`.

## Notes

- Commit `.agent-relay/` when you want the notes on the branch. Otherwise add
  the directory to `.gitignore`. This repo does not choose.
- Run ids come from `atry run new`. They do not need a network call.
- v1 files such as `plan.md`, `meta.md`, and `history.log` are not part of
  this layout. `atry` does not read them.

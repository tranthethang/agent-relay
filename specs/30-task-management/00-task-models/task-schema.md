# Task Schemas

Tasks are defined in two primary files under `10-plan/`:

## 1. Input Scaffold: `10-plan/tasks.input.json`

Created during `atry plan new` and edited by agents:

```json
{
  "schema": 1,
  "tasks": [
    {
      "title": "Configure database migration runner",
      "deps": [],
      "files": [
        "src/db/migrate.ts",
        "package.json"
      ]
    },
    {
      "title": "Add user authentication endpoints",
      "deps": ["T1"],
      "files": [
        "src/api/auth.ts",
        "test/auth.test.ts"
      ]
    }
  ]
}
```

## 2. Final Index: `10-plan/index.json`

Generated by `atry plan done` after validation:

```json
{
  "schema": 1,
  "tasks": [
    {
      "id": "T1",
      "title": "Configure database migration runner",
      "deps": [],
      "files": ["src/db/migrate.ts", "package.json"],
      "path": "10-plan/T1.md"
    },
    {
      "id": "T2",
      "title": "Add user authentication endpoints",
      "deps": ["T1"],
      "files": ["src/api/auth.ts", "test/auth.test.ts"],
      "path": "10-plan/T2.md"
    }
  ]
}
```

`strict.plan` controls the task-count gate. When it is `true`, `atry plan done`
and `atry plan amend` reject more than eight tasks. When it is `false`, they
write the larger index and print a warning. The planning skill asks the user
whether to keep a larger plan before finalizing it.
